# Advibe — React Frontend

Interactive single-viewport AI Investor Discovery & Relationship Operating System built with **React 18 + Vite**.

---

## 🛠️ Tech Stack & Architecture

- **Framework**: React 18 + Vite (Hot Module Replacement, ES Modules)
- **Background Shader**: React Bits `WebThreads` hardware-accelerated WebGL 2.0 sine thread simulation (`ogl`) with real-time mouse convergence.
- **Styling**: Pure Vanilla CSS (`src/index.css`) with liquid-metal glassmorphism, responsive breakpoint locks, and custom tokens.
- **Components**:
  - `src/App.jsx`: Main landing page shell, header, responsive navigation, hero section, and stats footer.
  - `src/components/WebThreads.jsx`: WebGL2 glowing thread shader component.
  - `src/components/Modals.jsx`: Interactive modals for AI Intake, Investor Matching Universe, Outreach Drafts with human-in-the-loop approval, Architecture breakdown, FAQs, Pricing, and CRM demo pipeline.

---

## 🚀 Running Locally

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start Vite development server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
